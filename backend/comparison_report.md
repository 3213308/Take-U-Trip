# 单 Agent vs 多 Agent 对照报告

- 单 Agent：3 次/用例，共 15 次运行
- 多 Agent：3 次/用例，共 15 次运行

## 一、总览对照

| 指标 | 单 Agent | 多 Agent | 变化 |
|---|---|---|---|
| 总通过率（越高越好） | 0.93 → 1.00 (↑0.07) |
| Judge 均分（越高越好） | 8.20 → 8.53 (↑0.33) |
| 平均延迟 s（越低越好） | 9.35 → 20.17 (2.16×) |
| 平均 token（越低越好） | 7766.47 → 17940.60 (2.31×) |
| 平均 LLM 调用次数（越低越好） | 3.40 → 4.47 (1.31×) |

## 二、病灶分布对照

| 病灶 | 单 Agent | 多 Agent |
|---|---|---|
| Judge检查点未全过(<1.0) | 0/15 = 0.0 | 0/15 = 0.0 |
| schema/意图失败 | 0/15 = 0.0 | 0/15 = 0.0 |
| 工具漏调(missing_tools非空) | 1/15 = 0.07 | 0/15 = 0.0 |
| 预算不一致(budget_metrics失败) | 4/15 = 0.27 | 3/15 = 0.2 |

> 注：「预算不一致」由 evaluate_budget_consistency 判定，「分项合计远小于总预算（有结余）」也会被判失败，并非仅指超支，解读时需区分。
